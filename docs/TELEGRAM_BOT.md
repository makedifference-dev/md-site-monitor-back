# 🤖 Telegram Bot для MD Site Monitor

Telegram бот для получения мгновенных уведомлений о состоянии ваших сайтов.

## 📋 Возможности

- **Мгновенные уведомления** о проблемах с сайтами
- **Привязка аккаунта** к Telegram через email
- **Статус проектов** и мониторинга
- **Удобные команды** для управления

## 🚀 Настройка

### 1. Создание бота

1. Откройте [@BotFather](https://t.me/botfather) в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям для создания бота
4. Сохраните полученный токен

### 2. Настройка переменных окружения

Добавьте в файл `.env`:

```bash
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
```

### 3. Запуск

Бот автоматически запускается вместе с основным приложением.

## 📱 Использование

### Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Начать работу с ботом |
| `/link <email>` | Привязать аккаунт к Telegram |
| `/unlink` | Отвязать аккаунт от Telegram |
| `/status` | Проверить статус привязки |
| `/help` | Показать справку |

### Пошаговая инструкция

1. **Найдите бота** по имени или ссылке
2. **Отправьте** `/start` для начала работы
3. **Привяжите аккаунт** командой `/link your@email.com`
4. **Получайте уведомления** автоматически при проблемах

## 🔔 Уведомления

Бот отправляет уведомления при:

- **Первой подряд неудачной проверке** сайта
- **Проблемах с SSL** сертификатами
- **Критических ошибках** мониторинга

### Пример уведомления

```
🚨 Site Down Alert!

Сайт My Website недоступен!

🌐 URL: https://example.com
❌ Ошибка: HTTP 500: Internal Server Error
⏰ Обнаружено: 24.08.2025, 21:32:29

Пожалуйста, проверьте ваш сайт и устраните проблему как можно скорее.

Это автоматическое уведомление от MD Site Monitor
```

## 🔧 Технические детали

### Архитектура

- **Telegraf.js** - современная библиотека для Telegram Bot API
- **Интеграция с базой данных** - привязка через telegramId
- **Обработка ошибок** - централизованная система логирования
- **Graceful shutdown** - корректное завершение работы

### Безопасность

- **Валидация email** при привязке аккаунта
- **Проверка уникальности** Telegram ID
- **Обработка ошибок** без утечки данных
- **Логирование** всех операций

### Производительность

- **Асинхронная обработка** сообщений
- **Кэширование** данных пользователей
- **Оптимизированные запросы** к базе данных
- **Graceful handling** ошибок сети

## 🔗 Интеграция

### С системой мониторинга

Бот интегрирован с `MonitoringService` и автоматически получает уведомления о проблемах с сайтами.

### С системой уведомлений

Работает параллельно с email уведомлениями, предоставляя дополнительный канал связи.

### С базой данных

Использует Prisma ORM для работы с пользователями и проектами.

## 🚨 Устранение неполадок

### Бот не отвечает

1. Проверьте токен в `.env`
2. Убедитесь, что бот запущен
3. Проверьте логи на ошибки

### Не приходят уведомления

1. Проверьте привязку аккаунта (`/status`)
2. Убедитесь, что есть активные проекты
3. Проверьте настройки мониторинга

### Ошибки привязки

1. Проверьте правильность email
2. Убедитесь, что пользователь существует
3. Проверьте, не привязан ли уже Telegram ID
